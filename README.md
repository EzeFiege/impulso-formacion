# Impulso Formación - Plataforma Académica & LMS

Plataforma educativa interactiva con catálogo de cursos, carrito de compras, aula virtual con reproductor de lecciones, toma de notas en tiempo real, evaluaciones y exámenes interactivos con certificación verificable, centro de recursos descargables, sistema de orientación vocacional y panel de administración con gestión de cupones.

---

## 🚀 Características Principales

- **Catálogo & E-Commerce:** Exploración de cursos, filtros por nivel y categoría, detalle enriquecido y carrito de compras con cupones de descuento.
- **Aula Virtual Completa:** Reproductor de video integrado, control de avance, navegación entre clases y módulos.
- **Sistema de Notas & Apuntes:** Notas ancladas al segundo exacto de la clase con descarga en Markdown.
- **Evaluaciones & Certificación:** Quizzes interactivos por módulo y Examen Final cronometrado (20 min) con distinción de *Mención de Honor*.
- **Verificación Pública de Diplomas:** Consulta y validación de autenticidad de certificados mediante código QR o identificador único.
- **Centro de Notificaciones:** Notificaciones de estudio en tiempo real en la barra superior.
- **Modo Oscuro / Claro:** Selector global persistente con adaptación estética de alto contraste.
- **Panel de Administración:** Gestión de cursos, estadísticas de alumnos y administración de cupones y becas de estudio.

---

## 🛠️ Tecnologías

- **Framework:** React 19 / React Router v7
- **Estilos:** Tailwind CSS / CSS3
- **Iconos:** Lucide React
- **Lenguaje:** TypeScript

## 📦 Instalación y Ejecución Local

1. Clonar el repositorio:
```bash
git clone https://github.com/EzeFiege/<nombre-del-repo>.git
cd <nombre-del-repo>
```

2. Instalar dependencias:
```bash
cd academia_cursos
npm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.
